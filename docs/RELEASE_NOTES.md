**Showcase+ v1.2.1**，包版本与应用版本 **1.2.1**，构建号 **1005**。基于 v1.2.0 的播放与触摸修复测试包。

- 修复新视频已提交、旧帧仍盖在上面的路径：移除旧画面不再只依赖 playing 事件，也依据实际帧提交／解码计数恢复。真实 Chrome 中抑制 playing 事件已复现并验证；尚不能证明这就是实车行驶停帧的根因。
- 等待关键帧时，即使非关键帧持续到达也会限频重试 IDR；媒体／控制 WebSocket 建连增加超时与页面缓存恢复后的重连。
- 网页只打开时不再锁住 14 Pro Max 的本机触摸。手机与网页按实际按下交接；新端按下前取消旧端手势，旧端后续移动和松手不干扰新端。
- 改善多个拖动坐标合包到达时的限频；网页合并高频移动，保留短滑动和松手终点。失焦／尺寸变化／断线取消手势，控制积压时重新连接。
- 新增诊断：暂停／就绪／时间轴、解码与提交信息、页面可见性、旧帧遮罩、播放错误、控制队列和 inputOwner。便于区分手机来帧、浏览器解码、呈现与触摸归属。
- 保留免密码、HTTP 标准入口与 8080、可选 HTTPS/WSS、前台运行和发送 iPhone 的蓝牙音频。

安装前：停车，停止 CarPlay、关闭车机网络探测、退出 Showcase，再用 Filza 安装本 Release 的 rootless deb 覆盖 v1.2.0。保持 Dopamine 越狱激活。安装后重新开启探测、Browser Output 和 CarPlay，刷新网页，不用密码。网页诊断应显示 **1.2.1 / 1005**。

先停车验证手机和网页交替点击、拖动、长按，及旧端松手不会打断新端；配置与主动排障也在停车后完成。收帧和帧回调增加不等于实际画面内容变化。当前网页无车辆档位接口，本版没有实现或承诺绕过行驶视频策略；实车停帧是否解决仍需实际验证，不能仅据桌面通过下结论。

仅适用于 **iOS 16.2+ / arm64 / Dopamine rootless**。发布前运行真实原生桥接与手势仲裁、HTTP/WS 和 HTTPS/WSS 的 Chrome 1080p MSE／触摸、首个 IDR 丢失与 playing 事件缺失、有限恢复／历史清理、网络守护和新增诊断回归，并完成 iOS 编译、签名、deb 内容校验。提供 SHA256SUMS 与构建来源记录；详见附带 PLAYBACK_REVIEW.md。
