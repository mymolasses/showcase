# Showcase+ v1.7.2

应用／安装包版本 **1.7.2**，构建号 **1020**。适用于 **iOS 16.2+、arm64、Dopamine rootless 越狱环境**。

## 本次更新

- **比例自由调整**：取消“自动左右分列 · 最大高度”的固定比例输入上下限，允许填写有效正数。应用时四舍五入并显示两位小数，例如 `1.296` 会按 `1.30` 应用。默认值仍为 **1.45**。
- **增加 1.30 阈值提示**：手机和网页均提示，已知 CarPlay Dashboard 实现以内部区域的“宽 ÷ 高”判断布局，大于 **1.30** 时左右分列，小于或等于时上下排列。内部区域与整个输出画面不同，因此它是测试参考，不是所有输出分辨率或 iOS 版本的固定切换值。
- **保存所选比例**：网页刷新、App 重开后仍可恢复接收端保存的比例，支持低于 1.30 和高于原先 2.00 上限的输入。
- **保留有效尺寸保护**：零、负数、非有限值，以及保留两位小数后为零的输入无效。输出仍受支持的像素尺寸、总像素和设备能力限制；无法生成有效画面时会明确提示原因。

## 设置入口与使用方法

1. 覆盖安装本版，重新打开 Showcase+，确认“关于”和网页诊断显示 **1.7.2 / 1020**。
2. **刷新车机浏览器网页**，加载新版比例输入与提示。
3. 网页进入 **菜单 → 输出比例 → 自动左右分列 · 最大高度**；手机端进入 **显示 → 输出比例**，也可调整。
4. 填写“宽高比（宽÷高）”并点击应用。调小数值可增加允许的画面高度，调大可给左右排列留出更多余量。修改实际输出尺寸时会重新连接 CarPlay，请保持接收端 App 在前台。
5. 若希望直接指定尺寸，选择 **自定义宽高**；只在点击应用后生效，输入过程中不会反复重连。

自动模式会测量浏览器可用区域和像素密度，在所填比例约束及窗口可用高度内计算输出。以 **1600×1250** 的窗口为例：比例 `1.45` 对应 **1600×1102**，`1.30` 对应 **1600×1230**，`1.20` 则使用窗口高度，输出 **1600×1250**。实际源尺寸以发送 iPhone 返回的配置和网页诊断为准。

## 当前保留的显示功能

- 浏览器自动适配、自动左右分列最大高度、手机比例、固定预设和自定义宽高。
- 已取消旧的 **1080 像素输出高度限制**。自定义宽高为 **240–4096 的偶数像素**，总像素不超过 **8294400**，自定义尺寸的宽高比范围为 **0.4–4**。
- 自动浏览器模式保留 **1920 像素输出宽度预算**；自定义可请求更高宽度。手机原有默认分辨率预算保持不变。
- 默认完整显示、不裁切、不变形；提供铺满裁切选项及手机灵动岛避让。手机和车机共享一路 CarPlay 源，各自的显示缩放独立。
- 保留网页与手机触摸控制、长按、拖动、取消、输入交接和断线重连。音频继续由发送 iPhone 通过汽车蓝牙播放。
- 浏览器使用单一的 **H.264 → HTTPS/WSS → Worker → WebCodecs → OffscreenCanvas / WebGL2** 链路，需要可信 HTTPS 和相应浏览器能力。旧 MSE、JPEG、MJPEG、Broadway 和 WebRTC 显示模式已移除。
- 保留已有的设备绑定激活、可信 HTTPS 证书自动更新和连接热更新功能；公开安装包不包含个人激活凭据或证书私钥。

## 验证说明

已通过 iOS arm64 编译、原生控制与连接回归测试、真实 Chrome 解码及 GPU 出图、比例输入与舍入、设置恢复、触摸和重连测试，以及真实 dpkg 全新安装／覆盖升级检查。发布的 deb 已核对版本、构建号、来源提交和 SHA-256。

桌面与 CI 测试不等于实车验证。最终地图／音乐排列由发送 iPhone 的 CarPlay 决定；不同 iOS、车型和车机软件版本仍需实测。浏览器无法直接读取 CarPlay 内部布局，自动模式也不保证同时满足“无黑边、无裁切、始终左右分列”。

## 历史更新摘要

### 1.7.0 / 1018

- 新增手机和网页的自定义输出宽高，以及自动左右分列最大高度模式。
- 取消 1080 高度限制，显示浏览器可用区域、像素密度、目标与实际源分辨率。
- 新增设置保存、明确应用后重连及自定义尺寸微调；保留触摸、蓝牙音频和证书更新。

**1.7.1 / 1019 未正式发布**：原计划将最低比例放宽至 1.31，后按新的需求取消发布；由本版的自由比例方案替代。

### 1.6.1 / 1017

- 修正并发激活回归测试，覆盖单次设备绑定、幂等重试和撤销状态持久化；应用行为与 1.6.0 相同。

### 1.6.0 / 1016

- 新增设备绑定激活和 `car.littlepond.eu.org` 的可信证书自动更新。
- App 启动、回到前台及运行期间每六小时检查更新，网络或服务异常时保留可用的本地证书。
- 新 HTTPS 连接可使用更新后的证书，已有 WSS 会话无需中断；后续续期不需要反复安装新包。
- 证书签发与应用 Release 分离，DNS 凭据留在专用服务端；同时完善现有 VPS 的证书部署和更新检查。

### 1.5.0 / 1015

- 将五种浏览器显示模式替换为单一 Worker／WebCodecs／OffscreenCanvas／WebGL2 链路。
- 直接转发原始 H.264，移除手机端面向浏览器的 JPEG 转码及旧显示后端。
- 明确报告 HTTPS 或浏览器能力不足，保留分辨率设置、触摸、蓝牙音频、静态画面和有界重连。

### 1.4.2 / 1014

- 修复发送端忽略车辆／蓝牙设备后，接收端反复使用失效蓝牙密钥的一种重连死循环。
- 仅对确认返回 `PIN_OR_KEY_MISSING (0x06)` 的已记住设备进行有限恢复，不清空其他设备、AirPlay 控制器或热点设置。
- 修正“Wi-Fi → 配对”进度误报，普通 TCP 探测和 `GET /info` 不再被当成真实配对请求。
- 增加蓝牙错误、连接句柄／设备地址匹配，以及真实配对请求的回归测试。
