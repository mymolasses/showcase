**Showcase+ v1.4.0**，应用／包版本 **1.4.0**，构建 **1012**。适用于 iOS 16.2+ / arm64 / Dopamine rootless。

- 新增“输出比例”：网页菜单和手机“显示”均可选自动适配车机浏览器（默认）、适配手机，或多组固定分辨率。浏览器根据实际可用区域和像素密度计算，保持比例并限制在 1920×1080 范围内，尽量减少上下黑边。
- 修改输出尺寸后自动重新协商 CarPlay，保留配对并保持热点开启；页面自动恢复。菜单展开和细微尺寸抖动不会反复重连。首次自动适配可能出现一次重连，发送机决定最终输出尺寸。
- 手机按实际横屏与安全区域布局，支持 iPhone 14 Pro Max；默认完整显示、不裁切，灵动岛可选右侧、左侧、系统避让或关闭。手机显示与浏览器缩放独立；源视频仍共用一路，选择目标比例决定优先适合哪一端。
- “铺满”改为保持比例的裁切显示，修正原网页拉伸变形；完整／铺满的触摸映射同步更新。
- 为尺寸协商重连增加 IPC 会话代次隔离及读端文件描述符所有权，防止旧连接退出时停止新会话。新增实际浏览器输出选择、窗口变化、恢复、触摸，以及真实 socket 旧连接退出测试。
- 保留 1.3.4 的 FFmpeg CPU JPEG 后备、五种显示方式、触摸及手机蓝牙音频。

安装后确认手机关于与网页诊断为 **1.4.0 / 1012**。网页“菜单 → 输出比例”默认自动车机；需要手机优先时选择“适配手机屏幕”。手机“显示 → 灵动岛避让”默认右侧，完整显示默认不裁切。切换输出比例后请等待 CarPlay 重新连接，不必手动清配对。

Release 流程包含真实 Chrome、原生 JPEG / WebRTC、HTTP / HTTPS、iOS arm64 编译签名、dpkg 全新与升级解包和附件来源核验。自动测试不等于手机或实车验收，不承诺 D 档限制已解决。
