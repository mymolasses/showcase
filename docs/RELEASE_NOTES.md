**Showcase+ v1.4.1**，应用／包版本 **1.4.1**，构建 **1013**。适用于 iOS 16.2+ / arm64 / Dopamine rootless。

- 修复首次连接停在 Wi-Fi 的一处已通过抓包确认的原因：发送机将多个 iAP2 消息合并到同一 RFCOMM 回调时，旧代码只处理第一条，丢失后续连接状态与传输标识。现在按字节流重组并处理全部完整报文，也支持一条报文跨多次回调。
- 校验报文长度、头和载荷校验和；限制控制消息读取范围。对重复报文重新确认但不重复执行，正确处理序号回绕，避免 ACK-only 报文推进接收序号。
- Release 改为从当前源码编译并签名 Bluetooth 助手 CarDisplaySim，记录其源码及解析器哈希，确保修复真正进入 deb；继续使用原有 rootless BTstack 守护进程和客户端库。
- 保留 1.4.0 的车机／手机输出比例选择、灵动岛避让、五种网页显示方式、触摸和蓝牙音频。

安装后确认手机关于与网页诊断为 **1.4.1 / 1013**。先验证首次自动连接和划掉重开，再测试车机／手机比例切换。无需因本次修复删除已有配对或热点设置。

Release 包含模拟抓包的合包／全部拆分位置／逐字节／重传／序号回绕／错误校验与长度测试，以及浏览器、原生服务、iOS arm64 编译签名和 dpkg 解包检查。模拟测试不等于实机验收；此修复针对已定位的丢消息问题，不承诺消除所有 Wi-Fi 连接故障或车机 D 档限制。
